# 🍰 Pastelitos Yeju

Sitio web desarrollado para **Pastelitos Yeju**, un negocio dedicado a la elaboración y venta de productos de repostería.

El proyecto funciona como un **catálogo web**, permitiendo a los visitantes conocer los productos disponibles, consultar información detallada y acceder a los medios de contacto del negocio.

## 📋 Características

* 🏠 Página de inicio
* 🍪 Catálogo de productos
* 🔎 Información detallada de cada producto
* 🖼️ Galería de imágenes dentro de los productos
* 🔗 Enlaces entre productos relacionados
* 📱 Diseño adaptable a dispositivos móviles
* 📲 Enlace directo al perfil de Instagram
* 📞 Información de contacto
* ✨ Animaciones y efectos visuales
* 📜 Navegación con desplazamiento suave entre secciones

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## 🚀 Ejecución

No se requiere instalación de dependencias.

Para visualizar el proyecto:

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en un navegador web.

También puede ejecutarse utilizando una extensión como **Live Server** en Visual Studio Code.

## 🎯 Objetivo del proyecto

Desarrollar un sitio web funcional y visualmente atractivo para presentar los productos de Pastelitos Yeju, utilizando tecnologías web fundamentales y aplicando conceptos de diseño responsive, interacción con JavaScript y organización de contenido.

## 📌 Estado del proyecto

**Versión 1.0 — Catálogo web**

Actualmente el proyecto está enfocado en la presentación de productos y la información de contacto.

En futuras versiones podrían incorporarse nuevas funcionalidades conforme aumente el catálogo y las necesidades del negocio.
